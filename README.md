## Projetos em destaque

### WebLib — Sistema de Gerenciamento de Biblioteca

Sistema web desenvolvido com ASP.NET Core MVC como projeto de estudo, aplicando conceitos de arquitetura, persistência de dados e regras de negócio.

**Tecnologias:** C#, .NET, ASP.NET Core MVC, Entity Framework Core, SQL Server e Bootstrap.

- Gerenciamento de livros, autores, editoras, categorias e usuários.
- Controle de exemplares e empréstimos.
- Organização do código em Models, Views, Controllers, Repositories e Services.
- Integração com banco de dados e uso de migrations.

### BuscarCEP

Projeto web para consulta de CEP utilizando a API ViaCEP, com apresentação dos dados retornados e interface desenvolvida com HTML e CSS.

**Tecnologias:** HTML5, CSS3, JavaScript e API ViaCEP.
